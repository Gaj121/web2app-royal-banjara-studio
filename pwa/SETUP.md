# PWA Setup (optional)

Website ko browser se install hone wala app (PWA) bhi bana sakte ho:

1. `icons/` folder aur `manifest.json` apni website ke hosting par upload karo
2. Apni website ke `<head>` me ye line add karo:
   `<link rel="manifest" href="/manifest.json">`
3. Bas — ab Chrome me "Add to Home screen" ka option dikhega
